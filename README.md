# 8415Wallet and 8415EX

This repository presents the Wallet and EX products, release information, and
selected ERC-8415 implementation examples. Public installation downloads are
limited to V2. V3 is not offered as a public installation download; its
installation packages are distributed separately through private channels.

## 8415Wallet

8415Wallet is a general-purpose wallet with native ERC-8415 support and compatibility with existing wallet and asset standards.

## Features

- Native ERC-8415 views for the tradeable position, register-confirmed holder, temporal finality, open gaps, and transaction history.
- Support for ETH and explicitly configured ERC-20, ERC-721, and ERC-1155 assets on supported networks.
- V2 standalone wallet features.
- V3 linked-responsibility features are described for product context only; V3 installation packages are not publicly downloadable.
- User-approved, bounded task permissions and durable activity records.
- External wallet signing that keeps private keys with the user's wallet provider.

Supported operations and networks depend on the product version. Record agreement does not establish legal identity or title.
